
# CGF Final Project — Concert Stage

## Project Description

A real-time interactive 3D concert stage
developed using C++, OpenGL 3.3 Core and GLSL.

## Technologies

- C++17
- OpenGL 3.3 Core
- GLFW
- GLAD
- GLM
- CMake

## Team Members

- Participant 1 — Stage and 3D Models
- Participant 2 — Lighting and Shaders
- Participant 3 — Audience and Animation
- Participant 4 — Camera, Controls and Light Show
- Participant 5 — Music, Effects and Integration

## Project Structure

- include/ — header files
- src/ — C++ source files
- shaders/ — GLSL shaders
- assets/ — textures and other resources
- external/ — third-party dependencies
